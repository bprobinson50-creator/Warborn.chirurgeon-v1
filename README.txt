WAR BORN SYSTEM v1.0

This is a phone-first Progressive Web App (PWA).

FASTEST WAY TO TEST
1. Extract this ZIP on a computer.
2. Open the folder in a simple local/static web server. (Opening index.html directly will show most of the UI, but PWA installation/offline support requires HTTPS or localhost.)
3. For phone installation, upload the folder to any static HTTPS host.
4. Open the HTTPS address in Chrome on Android.
5. Chrome menu > Add to Home screen / Install app.

DATA
- Activity Log entries are saved in the browser's localStorage on that device.
- Use Export Save in the Log tab to create a JSON backup.
- v1.0 does not automatically sync with ChatGPT.
